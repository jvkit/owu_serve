## 🐛 Bug Fixes

### fix: 普通用户登录后看不到模型
- 现象：新建普通用户（如 `12@a.com`）进入后模型列表为空
- 根因：OWU 的 `BYPASS_MODEL_ACCESS_CONTROL` 默认关闭，`role=user` 会被 access 过滤，看不到 base model
- 修复：设置 `BYPASS_MODEL_ACCESS_CONTROL=true`
- 涉及：`stack/owu-local-backend.sh`；**服务器部署需在 `.env` 同步该变量**

### fix: gateway dashboard / 用户中心 500
- 现象：`GET /dashboard` 500
- 根因：gateway 后端要 serve `frontend/dist/index.html`，本地未构建 dist 导致 ENOENT
- 修复：构建 gateway 前端；本地开发改为 `vite dev` 热更新（5176）

### fix: 用户中心 iframe 打不开（本地 dev）
- 现象：OWU 里点「用户中心」iframe 404 / 跳到登录页
- 根因：OWU 的 dashboard iframe 指向同域 `/uc`，本地 dev 未配置 gateway 地址
- 修复：OWU 前端注入 `VITE_GATEWAY_URL` 指向 gateway dev（5176/gw）
- 涉及：`webui/src/routes/(app)/dashboard/+page.svelte`

### fix: NewAPI 报错「Missing Root Token」且模型丢失
- 现象：gateway 连 NewAPI 报反自动化错误、模型列表异常
- 根因：本地 gateway 的 `NEW_API_BASEURL` 用了默认不可达地址，且未用服务器 NewAPI 凭据
- 修复：本地 gateway 对齐服务器 `NEW_API_BASEURL`（172.16.16.110:3001）、`NEWAPI_PASSWORD`、`NEWAPI_ADMIN_ACCESS_TOKEN`
- 涉及：gateway 本地启动环境变量（未硬编码，走 env）
